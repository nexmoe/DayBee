# 声纹方案分批实施与验收

2026-10-12。由主代理负责接口、审核和验收，Grok 4.7 子代理实施。原设计见 `voiceprint-tuning.zh.md`。本文件逐批记录交付状态；任务已分配不等于已完成。

## 第一批：个人判定、身份切分、录入质量

三个子任务在同一工作区并行，严格按文件所有权实施。现有桌面迁移改动必须保留，不提交、不推送、不更改真实用户设置和声纹。

### A：个人判定基础

负责 `voiceprint/profile.go`、`manager.go`、`score.go`、`decide.go` 及新增 calibration/cohort/normalization 文件和测试。保留现有 API，其他子任务只依赖下列新增接口：

```go
type EnrollmentContext struct { Device string; EchoCancellation bool }
func Calibrate(groups [][][]float32, context EnrollmentContext) (*Profile, error)
func (m *Manager) SaveProfile(profile *Profile) error
func Compatible(profile *Profile, context EnrollmentContext) bool
func DecisionScores(profile *Profile, windows []WindowScore) []float32
func DecisionThresholds(profile *Profile) (low, high float32)
func DecideProfile(profile *Profile, scores []float32, echo []bool) (string, float32)
```

`WindowScore.Score` 和 `ProfileScore` 保持原始余弦，回声算法继续使用原始尺度。`DecisionScores` 输出判定尺度，阈值必须与其一致。无个人校准的现有 ERes2NetV2 档案走兼容路径，不能把旧余弦阈值套到归一化分数上。

新增 Profile 版本保存设备、回声开关和校准信息；深拷贝、校验、原子保存、失败恢复完整档案。用公开真实嵌入构造 cohort，记录来源、许可证、模型、人数和条数，不能用随机向量冒充公开语音特征。可使用现有 `/tmp/voiceprint-eval` 样本；约 300 条向量不等于 300 位说话人。基于独立录入段的交叉验证，避免相邻重叠窗口泄漏。实现有边界的 AS-norm、个人高低阈值与明确的不确定区；注册质量不足返回可处理错误。

审核修订：公开 corpus 中 SSB0544、SSB0700、SSB0693、SSB0434 的所有语句保留给独立评测，不能进入 cohort。其余 9 人可提供约 288 条真实窗口向量，人数和条数必须如实记录。校准可行性的条件是满足误接受上限的最低阈值不超过满足本人召回下限的最高阈值，不能照搬原设计中对高低分位数关系的错误解释；最终迟滞阈值仍必须满足 low < high。校准负样本统计排除查询向量及其同说话人的全部向量，避免相关窗口进入归一化参考统计产生自偏。

### B：身份切分与转写接入

负责新增 `voiceprint/spans*.go`，`recorder/voice.go`、`segment.go`、`batch_voiceprint.go` 和相关测试；必要时小幅扩展 ASR worker，并维护其原有队列和关闭语义。

```go
type IdentitySpan struct { Start, End int; Identity string; Score float32 }
func (m *Manager) MatchSpans(p *Profile, samples []float32, rate int, ref *Reference) []IdentitySpan
```

身份使用 `me`、`not_me`、`uncertain`，只有 `me` 写标签。先平滑，再按个人高低阈值迟滞判定；身份变化持续至少 1 秒才切换。输出覆盖全部输入的连续、不重叠样本区间，短尾段保留。回声窗口不能被平滑为本人；无可用模型或设备不匹配时保留全部音频与转写，不贴本人标签。

实时和批量按身份区间分别解码并保存各自时间戳；不丢字、不重复转写；CPU 推理不得放在采集回调或录音事件循环中。不得在 ASR worker 回调内阻塞等待同一 worker。现有 fake matcher 保持兼容。上下文放宽只限同一录音、短间隔、高置信本人且无系统声音、无回声与设备变化，并用测试证明不发生错误传播。

### C：录入质量与设备绑定

负责 `desktop/voiceprint_enrollment*.go` 和相关测试、中英文声纹提示。调用 A 的 Calibrate/SaveProfile，不修改 A/B 文件。

收集环境噪声估计 SNR，低于 15 dB 提示重新录入；检测系统播放时暂停并明确提示，采样不归档；保留爆音拒收。跨段一致性检查剔除或拒绝异常录入；保持三段各 8 秒加 4 秒独立验证，验证不得混入注册。使用实际输入设备 ID 和回声配置，取消、超时、验证失败和设置保存失败均保留原完整档案并释放采集资源。修复先前的 VAD 计时/实际音频长度差异不得退回。

采集接口由 C 一并扩展 `audio/capture.go` 和 `capture_malgo.go`：`CaptureOptions.SystemReference` 请求可降级的内存参考，`OnReferenceUnavailable func(error)` 明确报告参考不可用。`SystemAudio` 仍表示用户要求保存的系统录音，保留其严格失败语义。禁止通过错误字符串猜测麦克风与系统源的失败。

## 第二批：系统参考与完整评测

第一批审核后，分配以下三个任务：

1. 系统参考与在线 cohort：声纹已启用时，即使不保存系统录音，也获取仅在内存中的系统参考；无权限或不支持时普通录音仍可用并说明能力降级。与系统录音开关解耦，不偷偷保存系统音频。实时参考在异步作业开始前冻结，避免 30 秒缓冲过期。在线系统 cohort 最多 500 条，按时间淘汰，禁止混入本人和错误模型。
2. 完整评测：以生产 MatchSpans/回声/投票/校准流程评测，公开音频构造本人、他人、外放回声、重叠和设备/噪声变化场景；训练、校准和测试按独立语句拆分。输出 FAR/FRR、召回、不确定比例、各时长指标、完整时间覆盖、耗时和 ASR 吞吐影响；新增本地可选样本导出入口，不上传录音。
3. 在线自适应与界面验收：默认关闭的可选自适应池最多 32 条，只有持续高置信本人、系统静音、设备匹配才加入；不修改注册向量，提供清除。补齐设备变化提示、校准/录入质量提示及中英文端到端测试。可选说话人聚类模型若增加下载成本，应明确保留为可选，不冒充已实现。

### 第二批设计约束

- 固定公开 cohort 决定 AS-norm 的尺度和个人阈值；运行时系统 cohort 作为额外的冒认者否决参考，不直接改变归一化统计。追加参考不能让原有的拒绝变成接受。系统 cohort 仅在内存保存，500 条为硬上限，清除声纹和模型/设备切换时失效，输入向量必须有效且来自活跃系统音频，拒绝本人相似向量。
- 仅参考模式不创建系统归档、系统转写或虚假的历史记录；其状态与用户是否保存系统录音分开。参考不可用须在界面显示，普通录音继续；麦克风故障仍按现有恢复逻辑处理。
- 队列内的任务持有入队时系统参考与设备/AEC 上下文快照，不能在 ASR 完成后才读取 30 秒缓冲；单任务引用样本有界，队列仍沿用原有上限。
- 评测四位独立说话人 SSB0544、SSB0700、SSB0693、SSB0434 不进入 bundled cohort。每人的注册与测试以完整语句拆分，不能把同一句相邻重叠窗口放到两侧。测试结果不反向用于该次个人阈值选择。
- 主指标来自生产 `MatchSpans`，逐样本对齐真值计算本人召回、非本人误接受与不确定比例；分别列出短语音、干净本人、他人、延迟混响外放、本人视频外放、重叠、噪声、设备变化。短音频被保留但不标本人属于明确的未判定，不能从分母删除。
- 延迟与性能至少包括嵌入线程数、窗口耗时、端到端分析时间，以及真实 ASR 同一批音频在声纹开关两侧的耗时与解码次数。对说话人切换的评测检查全长覆盖，不能只给分类准确率。
- 样本导出由用户明确点击触发，仅导出已有本地录音和侧栏说明；不为导出自动开启系统音频保存，不上传，不包含注册向量，路径与文件名冲突要安全处理。
- 自适应默认关闭；关闭不采样。候选必须来自原注册档案的高置信判定，不能用池自身证明下一条样本有效。池只提供受限的辅助匹配，不允许绕过系统回声、设备绑定或原注册的低阈值否决；阈值尺度继续绑定固定 cohort。清除池不清除原注册。
