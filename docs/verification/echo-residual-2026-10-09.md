# 外放回声残留验证

环境：macOS 27.0、内置麦克风与扬声器，系统声音单独录制关闭，Voice Processing 回声消除开启，自动增益关闭。

## 复现

整段录音直接送入 Qwen3 返回空文本，不代表生产管线无残留。使用实际 Silero 的 512 样本窗口、原有阈值及分段参数后，旧处理录音中有 1.73 秒残留触发转写。已添加 `TestEchoCancellationVADAcceptance`，逐段检查识别结果，并要求已知播放对照与现场语音对照。

原始 malgo 麦克风对照过于安静，没有触发 Silero，不能据此计算声学回声衰减或宣称配对验收通过。显式使用数字播放 WAV 时，只能证明分段和识别器对已知对白敏感。

## 未上线的人声过滤实验

- 使用独立 Core Audio HAL 人声检测，保留前后 200 ms，拒绝样本置零，保持时间轴。
- 现场语音经分段识别后，过滤前后文本一致，语音段约 3.46 / 3.49 秒；检测到现场人声，未把全静音算成功。
- 十秒外放没有触发检测，但 33 秒连续外放仍有 5.45 秒片段触发转写，实验未通过完整验收。
- 该片段与数字播放源的归一化相关性约 0.39，最佳延迟约 218 ms；说明仍可从播放参考中找到对应关系，不能只靠另一道人声检测解决。
- 生产 `newVoiceCapture` 不启用实验检测，未把实验安装到日常使用的应用。

## 测试环境限制

测试过程中日常 RecBee 被重新启动，产生了两个 Voice Processing 实例：日常应用录到了现场测试句，而测试进程未录到。相关现场测试结果无效，不能归因为用户未说话或过滤误挡。新硬件测试会在开始及结束检查日常 RecBee 是否运行；现场采集同时保存过滤前后 WAV，并核对麦克风授权。录音先于可选语音提示开始，支持较长窗口，避免文字提示与录音时间错开。

## 后续验证

当前尚未完成修复。需要采集实际系统播放参考与麦克风的同步样本，验证更强的对消或残留识别。`TestSystemAudioHardwareCapture` 已支持把两路测试音频分别保存到本机临时目录；普通测试不访问系统声音。执行前需获得 macOS 系统声音采集授权，不修改日常录音设置。
