# ERes2NetV2 模型切换验证

日期：2026-10-11。

当前默认模型为 `3dspeaker_speech_eres2netv2_sv_zh-cn_16k-common.onnx`，192 维，CPU 两线程。初始阈值 `0.537` 来自 [离线评测](voiceprint-eval.json)。模型下载和缓存按文件名区分，不复用 CAM++ 文件。旧 CAM++ 档案保留在磁盘上，但不会载入新模型；已配置声纹的设置回到待录入状态，重新录入成功后写入新模型的版本 2 档案。

## 录入问题与修复

使用评测已下载的 AISHELL-3 公开语音和真实 Silero VAD 运行 `TestNativeVoiceprintEnrollment`，原代码可复现：进度累计到 8 秒后，报 `The speech sample was too short. Please try again.`。

原因是录入进度累计的是 `Detected()` 状态持续的帧数，VAD 会在结束语音段时裁掉部分尾部，两者不保证相等。原代码达到进度目标便停止麦克风，再检查实际语音长度，导致有效录音提前失败。

现在达到估算目标后先取出 VAD 缓存，只有实际音频也达到目标才结束采集。不足时保留已收集的语音、校正进度并重置 VAD，继续采集；静音、取消和超时仍遵循原有规则。

## 验证

- 新增回归测试先在原逻辑上失败，修复后通过：持续说话会补足音频，后续静音会超时，麦克风均正确释放。
- 旧模型的版本 1、2 档案均拒绝加载，原文件保持原样；重新录入后新档案可重新加载。
- 在当前和旧版缓存中存在 CAM++ 文件时，仍下载 ERes2NetV2 至独立路径，不覆盖旧模型。
- 真实模型测试使用评测已下载的公开语音 `SSB0544_247.wav` 和 `SSB0700_265.wav`：同人识别、他人排除、完整三段录入加验证均通过，测试包含竞态检测。
- 最终 `go build ./...`、`go vet ./...`、包含上述真实模型测试的 `go test -race -count=1 -timeout 12m ./...` 全部通过；仓库根目录的 `bun run typecheck` 通过。

全量测试在沙盒外执行，因为现有测试需要本地 HTTP 测试端口、macOS 系统字体以及 Go 构建缓存。沙盒内出现的访问限制未通过修改应用代码来规避。

以上使用公开音频回放到测试采集接口，没有访问用户麦克风或修改已保存的用户声纹。真实房间中的外放回声和重叠语音准确率仍需实测。
