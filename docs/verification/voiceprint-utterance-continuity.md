# 发言连续性修订

日期：2026-10-12。用户反馈同一说话人的连续发言被拆成多个时间线节点，身份在本人与未识别之间跳变。

## 根因与复现

此前 `decodeIdentity` 与批量 `labelSpanPiece` 把声纹置信区间直接切成 PCM，逐段独立 Decode。时间线又按 `voiceIdentity` 的变化拆节点。`not_me` 与 `uncertain` 都只落盘为空身份，界面显示“未识别说话人”，把身份置信不足表现为换人。窗口分数受语音内容与短尾影响；guard 保护也会生成 uncertain，它们都不是说话人切换证据。

主代理只读复核了用户所指的本地记录与两段原音，完整输入的转写能保留连贯表达。原文件、档案与设置均未改写。本地原音不进入回归仓库或远程子代理；以下测试使用合成数据和公开 AISHELL-3。

修复前独立合同失败：

- `TestConfidenceChangesKeepOneUtterance`：混合置信的同一 VAD 被解码 2、3 或 4 次。
- `timeline-confidence-contract.test.ts`：同一采集区间生成 3 个节点；再接一个独立未知区间时生成 4 个节点，预期分别为 1 和 2。

## 行为合同

一次 VAD 完整解码一次，保存一条文稿和完整起止时间，实时与批量一致。核心声纹分析仍使用完整音频，阈值、边界保护、设备/AEC、回声否决、快照冻结与学习门不变。

- 全部身份区间为 `me` 且上下文兼容：整句“我”。
- 有本人区间也有其他区间：`voiceIdentity` 留空，`voiceMatch: "partial"`，显示“部分匹配本人”。此摘要不表示整句都是本人，不延续下一句的 anchor。
- 没有本人证据或上下文不兼容：身份未确认，无 partial。

历史文件中，同一录音、音源和有效 `capturedRange` 内时间连续的片段可以合成节点；各段原证据保留，全文与时间范围完整显示。跨采集区间的身份变化、应用场景、音源和时间间隔仍保持边界。缺少可靠采集区间时不猜测合并，不改写历史数据。

## 限制

这次修订解决置信波动切碎音频和时间线的问题，没有训练新模型、调低阈值或证明本人召回提升。一次 VAD 内若有多人，保留完整文稿并给部分匹配提示，不提供独立说话人轨道。历史独立解码时漏掉的字不能靠前端合并恢复，需要用户主动重新转写原音。

旧运行时评测的分类统计仍是内部声纹区间统计，不能当作修订后整句徽章准确率。旧性能报告按身份区间 Decode 的次数与耗时属于历史路径，不能再用于描述当前转写策略。一次完整解码失败时整句没有文本，原音保留并标记转写未完成；此前分段解码可以留下部分文本。

## 验证

- 全部 Go 包 `go test -race -count=1 -timeout 12m ./...` 通过；desktop 23.018s、recorder 6.399s、voiceprint 3.088s。
- `TestNativeUtteranceASRContext` 使用两个真实本地模型和公开音频，race 通过，10.496s：干净本人整句为 me；本人—他人—本人有 4 个内部置信区间，但只有 1 次完整 Decode，整句为 partial；纯他人、本人视频播放均无 me/partial。四段分别保留 8.856、12、11.910、8.856 秒的完整输入，产生四条非空文稿。
- 修订后的公开性能测试通过，94.869s。四种音频、三个模式、每模式三次测量，共 36 次均为一次完整 Decode；拼接语音的 4 个置信区间不增加解码次数。完整记录见 [性能复测](voiceprint-utterance-performance.json)。同次测试先逐片段预热，再固定次序测量；没有测队列等待、进程 RSS 或长期内存，不能与旧报告作受控速度提升比较。
- `go vet ./...` 通过；前端 typecheck 与 Vitest 71 项通过，包含 8 项独立连续性合同。审核补出的重叠 chunk、重复采集区间用例先失败，修复后通过；它们不能用来消除身份边界。
- 原生 `node scripts/desktop.mjs build` 通过，生成新的 darwin-arm64 `RecBee.app` 与 DMG；`verify-package.mjs` 的签名、许可证、原生库加载和音频兼容检查通过。没有重启用户正在使用的实例或修改其设置。
- 13 份相关 E2E spec 共 41 项最终通过。首轮 38 项通过；紧凑窗口搜索不存在、正常参考状态在设置卡中已隐藏这两处脚本旧假设导致 3 项失败，修正断言后定向复跑 3 项全部通过（4.7s），未因此修改产品行为。
- 独立 UI 合同检查历史混合片段全文、完整 0–8 秒时间范围、新 partial 与下一句未知保持分开、未确认内容不被标为我、主窗口搜索及两种窗口无横向溢出。主代理目视复核了中英文主/紧凑窗口截图，混合结果为中性颜色，全文只显示一次。
